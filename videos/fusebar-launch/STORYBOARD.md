## V2 direction
Continuous object identity, precise curved paths and unhurried readable holds. Pale #F4F8FC, ink #0B243B, accent #0076E8. No endorsement or claim that system icons automatically disappear. Intro is a menu-bar reconstruction, labeled as a concept. Native app panel is rendered from production SwiftUI and a live local snapshot. New volume-dot/hotspot features are a development preview; existing v1.0 release predates them.
