# FuseBar 1.0.1

Four dots now show approximate output volume in the menu bar. Charging, mute and other priority alerts replace the dots when needed.

This release fixes false Wi-Fi disconnection warnings when CoreWLAN cannot read the current connection. Personal Hotspot-class metered Wi-Fi uses the system chain-link symbol; normal Wi-Fi keeps its signal indicator. Network changes refresh promptly, including during startup.

Free, native and local. Requires macOS 14+. Universal app for Apple Silicon and Intel. The interface is Simplified Chinese. Hide redundant system icons manually in System Settings; FuseBar does not hide them automatically.

The app is signed with Developer ID and notarized by Apple. Download the ZIP, unzip it and move FuseBar.app to Applications. SHA256SUMS.txt is generated by the verification Action.

Note: the hotspot icon uses the system's expensive-Wi-Fi flag. It does not identify a phone manufacturer and may also appear for another metered Wi-Fi network. Seventeen automated tests passed; full cross-device/OS testing remains incomplete.
