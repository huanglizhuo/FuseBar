FuseBar is a free native macOS menu bar utility. No account, sign-in, purchase or subscription is required. Launch FuseBar and click its ring icon in the menu bar; it does not display a Dock icon. Finish the introductory screen with Get Started (开始使用). The interface supports English, Simplified Chinese, Japanese, French and Spanish.

Location entitlement: com.apple.security.personal-information.location is used for the optional display of Wi-Fi network names and nearby networks through public CoreWLAN APIs. macOS restricts these operations without Location Services authorization. FuseBar does not request geographic coordinates or start location updates. Network names are processed locally and are not uploaded.

To review this feature, turn on Wi-Fi, open FuseBar's menu bar panel, then click the Wi-Fi status row to open its side panel. With permission not granted, the panel explains the purpose and provides Allow network names (允许网络名称), or Check location access (检查定位权限) if previously denied. Grant access to see network names and scan results. If authorization was already granted, names and results appear directly. System Settings > Privacy & Security > Location Services contains the permission control. Battery and audio features remain usable if permission is denied. The system prompt and in-app explanation are localized in all five supported languages.

Bluetooth access is optional and used to display paired devices and connect or disconnect them only on user action. App Sandbox is enabled. User-selected files and project folders use security-scoped bookmarks. No private API, screen recording or accessibility permission is used. FuseBar does not automatically hide or modify other apps' menu bar items. Launch at login is explicitly user controlled. All app status data and preferences remain local.
