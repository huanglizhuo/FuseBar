# FuseBar：为 Vibe Coding 腾出空间

2026-09-17，本轮已授权实施范围。目标：用户自行自动隐藏 Dock 后，仍能快速启动/切换开发工具与打开项目入口。释放空间来自系统 Dock 自动隐藏；FuseBar 不修改 Dock 偏好，也不声称增加固定像素面积。

## 本轮交付

1. 可自定义全局快捷键：设置中录制组合、清除、持久化，注册失败保留原组合并显示错误。至少两个修饰键且含 Command 或 Control，避免普通打字被拦截；Escape 取消录制。不申请辅助功能或输入监控权限。快捷键打开首页并聚焦搜索，重复按关闭，Escape 关闭；鼠标仍按原入口行为。
2. 首页预设：保留状态优先；可切换编码布局（紧凑状态、应用架、项目入口）。应用架位于首页搜索框上方，每行 6 个、最多两行；超过 12 个时展示前 11 个，末格省略号进入完整列表。可选固定+运行或仅运行；固定未运行应用保留在列表；首页按最近激活或启动排序，顺序本地保存，未记录项回退固定顺序/启动时间。首页右键固定/排序/Finder 定位；显示当前前台 app 与运行标记。
3. 应用访问：持久 Shelf 不随弹窗重建；通过进程生命周期监听记录最近激活或启动顺序，最新在前，普通刷新不重排。通过系统选择器添加未运行 app；从常用安装目录按需读取应用目录，搜索覆盖已发现应用并说明范围。搜索结果可上下选择、Return 打开，不执行 shell 命令。
4. 轻量项目入口：用户保存项目名、授权目录、预览与仓库 HTTP(S) URL。手动选择当前项目；可编辑删除，删除仅移除配置。目录用只读安全作用域书签，失效后重新选择；URL 校验禁止脚本、自定义协议和含账号密码的 URL。预览仅打开地址，不启动开发服务器。本轮不宣称编辑器会话/窗口恢复或自动运行脚本。
5. 引导：说明固定工具、快捷键、Dock 自动隐藏的设置入口和恢复路径。五语同步。设置采用滚动区限制高度，保持返回位置和重开首页规则。

6. 输入源与底栏：输入源在标准布局采用与电池/声音一致的状态行，编码布局为同排按钮；二级列表支持选择。默认中心图标显示两秒，设置可常驻，深浅色自适应。底栏左侧设置图标、中间 Apps/Windows/Files、右侧 Quit，右上帮助。
7. 系统选择器：文件、项目目录、应用选择器打开期间保持父弹窗，结束后恢复外部点击关闭。

## 验证门槛

- 单元测试：组合校验/编码、真实 Carbon 注册冲突与释放；固定/运行合并与溢出、稳定顺序；项目 URL 校验、保存重建、删除与当前选择恢复。
- 构建和既有状态/语言回归；原生离屏预览检查编码首页、快捷键设置、项目编辑页的五语布局。
- 区分注册测试、事件分发测试、真实物理快捷键、全屏/多屏与硬件写操作。未实测的明确列出。
- 不自动改变用户 Dock、网络、声音或系统隐私权限；本轮不发布 App Store/GitHub 新包，除非用户再次要求。

## 后续独立阶段

具体窗口选择与准确聚焦、当前显示器/指针附近浮窗、编辑器专项打开目录、工作场景批量动作、文件投递口。先做权限与沙箱验证，不把候选功能混入本轮已完成清单。

状态项已采用独立侧边子菜单；电池先展示详情，提供系统设置入口。保留主菜单，Escape 分层关闭，右边空间不足交由 AppKit 换边。设置和项目等仍在面板内导航。
