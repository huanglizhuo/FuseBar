# FuseBar：状态、应用与快捷操作需求定义

> 当前实现摘要（2026-09-17）：最近使用应用架、可配置快捷键、编码布局与项目入口、输入源读取/切换及主题图标已加入开发源码；底部为设置图标 / 居中三快捷按钮 / Quit，帮助在右上角。电池、Wi-Fi、声音、蓝牙和输入源采用独立侧边子菜单，设置/项目等仍采用面板内导航。下文保留阶段性决策/审计历史；最新界面以 [README](../README.md)、[编码工作台定义](CODING_WORKSPACE_PLAN.md) 和 [验证记录](VALIDATION.md) 为准。

更新：2026-09-16。本文定义下一阶段开发，未勾选项目不属于已发布功能。

## 产品定位

一个菜单栏入口，完成「看状态 → 调整设备 → 打开应用 → 找回窗口」。保留固定位置的电量环、Wi-Fi/热点和四点音量，不把 Dock 图标挤进 22 pt 圆环。完全免费、本机处理、两种发行渠道共用沙箱实现。

## 信息架构

- 状态：首页保留电池、Wi-Fi、蓝牙、音量；声音进入输出设备选择页。网络和蓝牙逐步升级为内部详情页。
- 应用：常用应用、运行中的应用、搜索、固定/取消固定；固定列表由 FuseBar 独立管理。
- 快捷操作：系统应用启动器（Apps/Launchpad）、所有窗口（Mission Control）；后续添加用户选定的文件夹。
- 设置与帮助：指标、登录启动、权限解释、系统设置兜底。不改变原生 Dock 或菜单栏图标的可见性。

页面使用有限高度滚动区域。返回不丢失用户固定列表；打开外部应用前关闭弹窗；失败重新显示明确错误。搜索只过滤本机应用列表，不查询网络。

## 功能范围与验收

| 优先级 / 功能 | 行为定义 | 验收 / 边界 |
| --- | --- | --- |
| P0 状态圆环 | 电量环、普通 Wi-Fi/热点、四点音量；异常按现有优先级覆盖 | 保留热点修复和全部状态测试；不添加新的常驻角标 |
| P1 应用启动器 | 打开系统 Apps 或 Launchpad | 找不到入口显示错误；不模拟按键 |
| P1 所有窗口 | 打开 Mission Control | 此名称指系统总览，不承诺逐窗口列表或恢复每个最小化窗口 |
| P1 运行应用 | 列出普通前台应用；点击激活 | 排除 FuseBar 和后台代理；启动/退出后列表刷新；真实运行标记 |
| P1 固定应用 | 从运行列表固定；未运行时可重新启动；可取消固定 | 按添加顺序持久化 bundle ID；重启保持；卸载后显示不可用，允许移除；不读写原生 Dock 偏好 |
| P1 应用搜索 | 同时过滤固定和运行列表 | 空查询恢复列表；无结果明确显示；当前阶段不是所有已安装应用搜索 |
| P1 声音输出 | 列出可作为默认输出的设备；切换默认媒体输出 | 使用稳定 UID 重新解析；切换中禁用重复操作；拔出/失败如实显示；系统提示音输出不跟随改写 |
| P2 应用管理 | 隐藏、显示、在 Finder 中显示；调整固定顺序；退出另作沙箱能力研究 | 用户逐项触发；当前沙箱不能通过 NSRunningApplication 退出其他应用；不提供强制退出或一键退出全部 |
| P2 Wi-Fi 选择 | 用户打开页面后按需扫描，排序、去重、显示当前网络；个人网络连接 | 名称/扫描按系统定位授权；密码仅存当前操作内存，不记录日志；企业认证和未知安全类型交给系统设置；扫描不加入每三秒轮询 |
| P2 蓝牙设备 | 授权后展示已配对设备；支持的经典蓝牙设备连接/断开 | 每类硬件实测后开放按钮；连接链路不等于音频路由成功；BLE/配对/系统总开关先交给系统设置 |
| P3 文件与文件夹 | 用户通过选择器添加 Downloads 等目录或文件；打开、移除快捷入口 | 安全作用域书签；拒绝/失效支持重新授权；不读取容器内的假 Downloads；第一版不做文件栈内容预览 |
| P3 最近使用 | 仅记录用户通过 FuseBar 打开的项目，可清除与关闭 | 不宣称全系统最近文件；不做使用行为上传 |
| P3 废纸篓 | 经验证可用的 Finder 入口 | 不实现清空、自动删除；未证实沙箱兼容前不出现假入口 |
| 研究项 窗口管理 | 每应用窗口列表、最小化/恢复、应用 Exposé、显示桌面 | 先研究公开 API、权限和双渠道可行性；若需要辅助功能授权，独立可选方案，不悄悄加入当前版本 |
| 暂不实现系统专属功能 | Handoff、其他应用的 Dock 徽章/动态 Dock 菜单、Spaces 管理、Stage Manager 控制 | 无通用稳定接口或权限/破坏性范围较大；保留原生系统入口，不能称完整替代 Dock |

## 实施步骤

1. **基础批次**：应用页、运行列表、固定与搜索、系统启动器/Mission Control、声音输出列表与切换。验证构建、模型测试、真实只读设备枚举、离屏界面；记录未实测操作。
2. **控制批次**：Wi-Fi 内部面板与按需扫描；对个人网络连接建立失败/取消/断网恢复模型；声音设备拔插、蓝牙硬件能力矩阵。先完成只读与权限，再开放写操作。
3. **Dock 扩展批次**：应用上下文操作和排序；授权文件夹/文件入口；最近使用和废纸篓入口。
4. **窗口增强研究**：独立技术验证后决定是否纳入。逐窗口功能不能以截图、私有 API 或模拟快捷键冒充稳定支持。
5. **发行**：macOS 14/15/26、Intel/Apple Silicon、沙箱、VoiceOver、设备拔插/拒绝权限/睡眠恢复；更新截图与 README；新版本签名、公证、GitHub Release、App Store 构建与审核。当前规划不更改已发布 1.0.1 的功能承诺。

## 验证规则

纯模型测试覆盖去重、过滤、固定顺序、失效项保留。设备写操作必须以系统回读为准，不能用乐观勾选伪装成功。不得为了测试随意切断用户当前网络、退出用户应用或清空文件。编译、模拟快照、只读真机枚举、沙箱实机点击分别记录；未覆盖的平台/设备保持待验证。

## 全量系统能力审计与本轮增量

完整菜单栏/控制中心/Dock 对照见 [官方能力研究](SYSTEM_CAPABILITY_RESEARCH.md)，代码缺口与旧规划纠正见 [实现审查](CAPABILITY_REVIEW.md)。研究表的“当前”是本轮开始前基线，以下为开发进度增量；仍不是已发布功能。

| 能力 | 本轮代码状态 | 尚需验证 / 剩余范围 |
| --- | --- | --- |
| Wi-Fi 内部页 | 按需扫描、SSID+安全类别去重、当前网络标记、个人网络密码连接、明确确认关闭 Wi-Fi | 未执行真实扫描/连接/电源写入；企业/隐藏网络、已知网络密码复用、Instant Hotspot 交给系统 |
| 蓝牙内部页 | 授权后的已配对设备与连接状态 | 连接/断开/配对/总开关仍为系统委托，不计直接支持 |
| 静音 | CoreAudio 可写检测、写入与回读；不支持设备禁用 | 真实设备写入/拔插测试；声音输入仍在下一批 |
| Dock 应用操作 | 右键隐藏/显示、Finder 定位、固定顺序持久化 | 沙箱内实际操作；其他应用退出被沙箱限制 |
| 文件/文件夹入口 | 用户选择、只读安全作用域书签、本地保存、失效提示、移除不删除 | 真实选择器授权、跨重启/移动文件测试；文件栈、指定应用打开、最近历史、AirDrop 分享待补 |
| 日期 / 低电量模式 | 系统功能页本地读取 | 非系统菜单栏时钟替代；不切换电源模式 |
| 系统功能目录 | 显示、专注、AirDrop、桌面与程序坞、键盘、辅助功能、通知、Time Machine、用户、日期时间、电池、菜单栏设置；日历/天气/快捷指令应用入口 | 所有均明确标注外部入口；设置 URL 跨版本跳转待逐项实测 |

拖文件给指定 app 和磁盘推出存在公开 NSWorkspace API，已从“无接口/系统专属”名单移至独立验证计划。下一步优先完成本轮真实操作验收，再补声音输入、添加未运行应用、文件栈/分享/快捷指令；窗口 AX、输入法、显示与 VPN 分专题验证。未来是否提供解除沙箱的 GitHub 增强版需单独定义，当前不改双渠道安全边界。


## 蓝牙交互修订（2026-09-21）

用户明确要求设备行直接连接，因此取代上文“连接/断开委托系统”的旧进度：直接调用公开连接与断开接口，配对和电源仍交给系统。按钮体现正在操作的设备、实际连接状态和错误；不把命令返回成功等同于实际连接，更不等同于默认声音输出已切换。支持范围与实测见 VALIDATION。名称以精确身份对应的系统音频名称优先，断开后使用本地缓存。
