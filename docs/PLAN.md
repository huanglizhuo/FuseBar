# FuseBar · 产品与实施计划

> 当前实现摘要（2026-09-17）：最近使用应用架、可配置快捷键、编码布局与项目入口、输入源读取/切换及主题图标已加入开发源码；底部为设置图标 / 居中三快捷按钮 / Quit，帮助在右上角。电池、Wi-Fi、声音、蓝牙和输入源采用独立侧边子菜单，设置/项目等仍采用面板内导航。下文保留阶段性决策/审计历史；最新界面以 [README](../README.md)、[编码工作台定义](CODING_WORKSPACE_PLAN.md) 和 [验证记录](VALIDATION.md) 为准。

## 产品决策

面向 macOS 14+ 的原生菜单栏应用。用一个固定 28 pt 宽的入口承载 18 pt 状态圆环。用户手动隐藏系统图标；应用不移动或注入其他菜单栏项目。无账号、后端、分析埋点、屏幕录制或辅助功能权限。

参考 [CircleStatusBar](https://github.com/artemnovichkov/CircleStatusBar) 的最终形态：开口圆环、居中的 Wi-Fi、底部连接点。已查看 comparison-sheet.jpg 和 WiFiGlyph 源码。参考项目是动画研究，不能直接提供电池或无线连接数据；FuseBar 独立实现绘制，不复制参考媒体或代码。

## 视觉与交互规格

- 外环：从左下端沿 280° 量程绘制电量，底部留对称的 80° 缺口供状态提示使用。背景细环表示量程，实线表示当前电量。无电池时不画电量环，未知时画虚线。
- 中心：热点类 Wi-Fi 路径显示官方 `personalhotspot` 链环；普通 Wi-Fi 使用官方 SF Symbol `wifi` 通过 variableValue 表示强度；关闭为 `wifi.slash`，断开为 `xmark`，未知为 `questionmark`。不能把 SSID 为空判成断开，也不能把 Wi-Fi 连接称为互联网畅通。
- 底部：固定在垂直中轴的单一状态提示位，正常时四点显示约 25%、50%、75%、100% 音量（向上取整）；未知或不可读音量时留空；优先级为严重低电 → Wi-Fi 断开 → 低电 → 充电 → 静音。多个状态不并排、不轮播；所有详情仍可在弹窗查看。蓝牙移至详情与可选悬停摘要，取消常驻连接点。
- 取消右上/右下角标。底部警告使用官方 `exclamationmark`，充电使用 `bolt.fill`，静音使用 `speaker.slash.fill`。符号位置恒定，不覆盖中心 Wi-Fi；严重低电和一般低电通过外环长度及文字详情进一步区分。
- 提醒标题优先级：严重低电量 → Wi-Fi 断开 → 低电量 <20% → 充电 → 静音 → 平静摘要。关闭的指标退出提醒计算。
- 单击打开 320 pt 宽原生 Popover：标题与摘要、四行状态、音量滑块、设置/帮助/退出。Escape 或点击外部关闭。悬停和 VoiceOver 读完整文字。
- 设置：电池、Wi-Fi、声音三项图标开关（允许全关，保留中性入口），以及独立的蓝牙悬停摘要开关、唯一 Compact Orb 外观、登录启动、图形说明与首次使用引导。点击打开弹窗始终启用，避免用户关闭后失去入口。
- 首次启动：展示“四个图标，一个入口”、图例与系统设置按钮。隐藏原生图标完全由用户决定；新 macOS 的路径可能为“菜单栏”，旧版本为“控制中心”。
- 系统字体、系统材质、原生按钮与焦点状态；中英文中的第一版界面采用中文，设备名称原样展示。

## 系统能力与降级

| 数据 | 实现 | 限制/降级 |
| --- | --- | --- |
| 电池 | IOKit IOPS，仅内置电池 | 桌面 Mac 显示无内置电池；读取失败为未知；外接电源但未充电单独说明 |
| Wi-Fi | CoreWLAN 电源、关联模式、RSSI、SSID | SSID 需定位授权；默认不请求，用户点击“显示网络名称”后才请求权限，不启动位置更新；名称不可用仍显示关联状态；不主动扫描网络 |
| 蓝牙 | CoreBluetooth 授权/电源 + IOBluetooth 已配对设备连接状态 | 用户点击后才请求权限；不扫描、不配对；未授权和未连接分开 |
| 声音 | CoreAudio 默认输出、主声道或左右声道音量、静音 | HDMI/USB 等无软件音量控制时禁用滑块，提供系统设置；写入失败可见 |
| 登录启动 | SMAppService.mainApp | 显示真实服务状态及系统待批准状态，不用本地布尔值伪装成功 |

读取在串行后台队列执行，初始 3 秒轮询、弹窗打开与唤醒立即刷新。禁止重叠刷新。休眠停止计时；改变后的快照才触发图标更新。首个可运行版的延迟上限目标约 3 秒，后续事件驱动替换轮询；不宣称当前已达到事件级实时更新。

## 架构

`SystemReader + AudioDevice → StatusSnapshot → StatusStore → OrbView / PopoverView`

- Domain：值类型快照、显示偏好、阈值和优先级纯函数，无硬件依赖。
- System：系统框架适配器，状态读取与音量写入集中封装。
- Store：主线程发布状态、后台采样、权限、偏好持久化、休眠/唤醒管理。
- UI：AppKit NSStatusItem + NSPopover，SwiftUI 矢量圆环与页面。ImageRenderer 生成 template NSImage 适应明暗菜单栏。
- 工程：XcodeGen 描述 + 提交生成的 Xcode 工程，零外部运行依赖；macOS 14 最低版本；本地 ad-hoc 签名。正式发行须 Developer ID、Hardened Runtime、公证与真机兼容性回归。

## 实施顺序与验收门槛

1. P0 规划与空工程：保存 PRD、产品决策、构建入口与状态模型。
2. v0.1：Battery + Wi-Fi、圆环、弹窗、未知/无硬件处理；构建通过、阈值与异常规则测试。
3. v0.2：蓝牙权限、已配对设备详情与悬停摘要；授权前不访问设备名称。
4. v0.3：声音读取、静音角标、可写音量控制；不支持控制的设备禁用控件。
5. MVP 集成：持久设置、引导、登录启动、设置跳转、VoiceOver 文本、休眠恢复、全状态预览与测试。
6. 发布前验证：Intel 与 Apple Silicon、macOS 14/15/26、浅/深色及高对比度、VoiceOver、拒绝权限、AirPods/HDMI/无电池、切换输出、睡眠、8 小时运行与能耗采样。验证前只能称开发预览。

## 产品验证

邀请 5–8 位 Mac 用户完成“一眼判断低电、断网、静音”任务；与原生图标比较准确率和时间。记录自愿隐藏的图标数（目标 ≥3）、一周内恢复原生图标的原因。仅访谈/本地记录，不内置遥测。若 18 pt 无法稳定辨认四状态，优先减少默认指标或调整几何，不继续增加状态种类。

## SF Symbols 选型修订

依据 [Apple SF Symbols](https://developer.apple.com/sf-symbols/) 与本机系统 CoreGlyphs.bundle 的 `name_availability.plist` / `symbol_order.plist` 核对名称和最低版本。所选符号均在 macOS 14 或更早可用；不引入图片下载或新依赖。

| 位置 | 选择 | 理由 |
| --- | --- | --- |
| 底部充电 | `bolt.fill`，6.5 pt regular | 实心轮廓在小尺寸下完整，在底部中轴固定显示 |
| 中心 Wi-Fi | `wifi`，8 pt semibold，variableValue = 档位 / 3 | 官方轮廓及分层信号强度，免去手绘弧线的比例偏差 |
| Wi-Fi 关闭 | `wifi.slash` | 直接表达关闭；断开仍用小 `xmark`，更详细的 `wifi.exclamationmark` 留给弹窗 |
| 底部警告 | `exclamationmark`，6.5 pt bold | 严重低电、断网、低电占用同一个提示位，不显示蓝牙连接点 |
| 蓝牙详情行 | `antenna.radiowaves.left.and.right`，关闭时 slash 版本 | 本机公开目录未找到 Bluetooth logo；这是通用无线符号，必须与“蓝牙”文字一起出现，不称其为官方蓝牙图标 |
| 弹窗电池 | `battery.0percent` / `25percent` / `50percent` / `75percent` / `100percent`；充电用 `battery.100percent.bolt` | 不再固定显示 75%；文字仍提供真实电量，充电符号仅表示正在充电，不表示已充满 |
| 弹窗声音 | `speaker.wave.1.fill` / `2.fill` / `3.fill`；静音用 `speaker.slash.fill` | 随音量档位变化；无可读音量时不假设档位 |
| 底部静音 | `speaker.slash.fill`，5.5 pt regular | 底部缺口加宽后可容纳完整静音符号；有更高优先级状态时仅保留在详情中 |

连续电量环与四点音量使用自定义 Path。底部提示、问号和中性圆形入口都使用系统符号。旧版蓝牙显示偏好键保留并用于悬停摘要，因此升级不会重置用户设置。

## 应用图标

应用身份采用“汇聚之环”：蓝绿色背景、玻璃状态环、两段汇聚信号和中心节点。使用 1024 px 原创矢量分层及原生 Icon Composer `.icon` 文档；Xcode 编译分层资源和兼容 `.icns`。见 [设计源文件说明](../Design/AppIcon/DESIGN.md)。菜单栏动态图标保持单色，以免 Liquid Glass 材质影响 18 pt 状态读取。

## 四点音量与热点修复（2026-09-16）

- CoreWLAN `.none` 同时可能表示读取失败，不再单凭该值断言断开。增加 Wi-Fi 专用 `NWPathMonitor`，已满足的 Wi-Fi 路径可弥补接口/关联读数缺失。仅以太网或 VPN 路径不会冒充 Wi-Fi。
- `isExpensive` 的 Wi-Fi 路径使用 `personalhotspot`；这是 Apple 对个人热点等计费网络的公开信号，不能精确证明设备制造商。详情如实称“热点 / 按流量计费网络”。不按 SSID、IP 地址猜测，不调用私有 API，不扫描网络。关联成功但路径不可用仍保留 Wi-Fi 连接状态，不把无互联网等同断网。
- 初次读取期间到达的网络路径更新会触发后续采样；网络变化会主动刷新，其余状态仍约三秒轮询。无新增运行依赖或网络请求权限。
- 底部四点沿缺口对称排列；音量 1–25%、26–50%、51–75%、76–100% 对应 1–4 个亮点。零音量显示静音，异常状态保持既定优先级。读数未知不画伪造音量。
- 宣传片 v2 的曲率动画适配 CircleStatusBar 的 MIT 实现，许可保存在视频目录；此项只用于视频，不改变应用绘制的独立实现。

## 系统快捷操作

状态页底部增加并排的“应用启动器”和“所有窗口”按钮。应用启动器优先打开系统 Apps.app，旧系统回退 Launchpad.app；所有窗口打开 Mission Control.app。通过 NSWorkspace 启动，先关闭 Popover，不模拟键盘快捷键，不引入辅助功能授权或私有 API。找不到入口或启动失败时显示真实错误。

## 菜单栏控制与 Dock 能力扩展

新需求以 [控制中心需求定义](CONTROL_CENTER_PLAN.md) 为准：第一批加入独立应用页与声音输出选择，后续按需网络扫描取代“永不主动扫描”的 MVP 限制。扫描只由用户进入网络面板或刷新触发，不后台周期扫描。窗口增强权限另行评估；当前实现继续不申请辅助功能权限。实际菜单栏绘制尺寸为 22 pt，固定入口宽 28 pt；早期 18 pt 为设计/图谱预览尺寸。


## 系统功能覆盖审计（2026-09-16）

完整范围见 [菜单栏/控制中心/Dock 官方对照](SYSTEM_CAPABILITY_RESEARCH.md)。保持“直接实现 / 系统委托 / 待验证 / 系统保留”区分，不宣称全系统等价替代。新增文件选择只读权限和应用作用域书签，存储用户明确选择的本地快捷入口；网络页面由用户按需扫描并明确选择连接操作。隐私政策同步描述本地处理。当前不增加跨应用辅助功能、录音、屏幕录制或自动化权限。

## 菜单栏热点尺寸与模板颜色修正

热点中心符号从 8 pt 缩为 6.5 pt，中心位置不变；普通 Wi-Fi 仍为 8 pt。菜单栏导出专用不透明黑色模板、显式单色 SF Symbols，最终前景色交给 NSStatusItem；弹窗与引导继续使用语义 primary。保留未填充轨道/音量点的有意透明度，不将它们混为亮度缺陷。

## 首页应用与声音交互（2026-09-16）

- 首页取消“应用”按钮，直接显示运行应用图标：每行 6 个，最多两行；超过 12 个时显示前 11 个，最后一格“…”进入完整运行列表。未超出时不占用额外省略号位置。常用应用管理仍可从设置进入。
- 启动器、所有窗口、文件夹、系统统一放在同一排小尺寸 bordered 按钮；窗口按钮短标题为“窗口”，帮助/辅助功能标签仍注明所有窗口。
- 音量改为拖动期间写入、40 ms latest-value throttle，百分比本地立即反馈。CoreAudio 监听默认输出与该设备音量/静音属性，设备改变后重新绑定；独立音频队列读回状态并保护旧轮询结果不覆盖新读数。保留 3 秒轮询作为未支持通知的降级。
- 待处理音量包含目标设备 UID；默认设备改变后旧请求拒绝写入。睡眠和退出时移除音频监听，唤醒重新注册。

## 弹窗导航

二级页面左上角统一“‹ 返回”，回到首页，支持 ⌘[；底部不再放返回按钮。每次重新展开 NSPopover 前创建新的页面视图，导航、搜索和临时表单回到初始状态，共享系统状态与持久化设置不重置。首次使用引导仍遵循完成标记。

菜单栏弹窗生命周期由应用统一管理：按钮在鼠标按下时切换，NSPopover 使用 applicationDefined；外部点击、应用失活与 Escape 显式关闭，状态按钮区域不会被外部关闭逻辑重复处理。只在弹窗展示期间监听，不增加辅助功能权限。

## 五语本地化与 GitHub 1.1.0

界面、状态摘要、错误提示、VoiceOver 和隐私权限说明支持英文、简体中文、日文、法文、西班牙文。按系统首选语言顺序匹配语言代码，地区变体共享同一翻译；中文变体使用简体中文，无匹配时英文回退。切换系统/应用语言后重启生效，不新增联网翻译或运行依赖。设备、应用、文件、网络名称保留原样。较长文案使用自然换行，首页快捷按钮保持同排小尺寸。

## 输入源融合（2026-09-17）

- 使用 Carbon Text Input Source Services 读取已启用、可选择的键盘输入源及当前选择；过滤不可选择的输入法父项，不扫描用户输入内容。

- 默认仅在输入源 ID 真正改变后替换中心 Wi-Fi 2 秒，快速切换重新计时；同源刷新不延长时间，启动不伪造切换。可在设置开启中心常驻输入法图标。Wi-Fi 详情及断网异常优先级不变。
- 首页搜索框下提供当前输入源图标/名称，点击展开已启用输入源列表，当前项显示勾选。选择后先关闭弹窗并恢复原应用焦点，再调用公开切换接口，核对读回结果；失败显示错误。
- 通过系统分布式通知响应输入源及启用列表变化。输入法内部 Shift 中英文模式不等于系统输入源切换，不承诺可检测。全程本地，无新增权限、私有 API 或运行依赖。

输入源主题修正：弹窗当前图标和输入源菜单项也使用单色模板，不再直接显示固定黑色原图；随系统语义前景色变化。状态栏最终 NSImage 继续标记 isTemplate，交由 macOS 着色。

输入法图标尺寸收紧：圆环中心从 9×9 pt 缩为 7×7 pt，中心位置不变；弹窗和输入源菜单统一为 14×14 pt，同时限制模板图片逻辑尺寸与 SwiftUI 显示框，保留主题着色。

首页固定与运行应用合并后按最近激活或启动排序，最新事件置顶；固定应用关闭后仍保留，未记录项保持确定顺序，运行应用使用启动时间补齐。应用切换监听随进程生命周期运行，关闭弹窗不停止；FuseBar 自身和后台代理不进入记录。仅在本机保存最近 100 个 bundle ID，普通刷新、隐藏/退出事件不改写使用顺序，重启保留记录。两行与省略号规则不变。固定管理中的手动顺序作为无最近记录项的回退。

## Wi-Fi 沙盒访问与未连接的声音设备（2026-09-21）

实际签名沙盒探针确认：缺少 `com.apple.security.network.client` 时，CoreWLAN 对 `com.apple.airportd` 的查询被拒绝；增加这一标准权限后能读取当前 SSID 并扫描附近网络。保留 App Sandbox，仅添加网络客户端权限，无私有 entitlement、后台网络请求或上传。Wi-Fi 扫描与连接复用 StatusStore 长生命周期定位管理器的授权结果，不再新建管理器后立即误读初始 notDetermined。扫描服务不可用、Wi-Fi 关闭、系统调用失败分别说明。

声音列表合并当前 CoreAudio 输出与已配对音频设备，用精确蓝牙地址去重，键盘鼠标不进入声音列表。没有音频通道的耳机仍显示名称和连接入口；用户点击后连接、等待最多约 10 秒的音频通道、切换并读回系统默认媒体输出。失败在菜单中显示且允许重试，不自动断开任何设备。蓝牙写入在两个入口间串行执行。

## 菜单响应性修复（2026-09-21）

菜单显示使用已有状态，不再在 show 前刷新输入源、应用目录和登录项。应用列表元数据/书签解析放到后台串行队列，保留当前缓存，至多一个读取和一个待刷新请求，丢弃旧版本结果；安全书签解析不隐式挂载卷。应用图标后台加载并缓存，输入源图标缓存到启用列表变化时失效。

CoreAudio 监听注册、移除和设备属性读取统一放入独立后台串行队列；50 ms 内的设备通知合并一次重绑，通过代次令牌拒绝停止或重绑后的旧回调。主线程仅接收最终状态。

耳机连接及等待输出通道使用独立连接队列；音量写入最多保留一个执行中任务和一个最新待写值，维持 40 ms 合并间隔。首页和声音子菜单统一忙碌禁用，切换输出时取消尚未执行的音量值，设备 UID 回读保护保留。声音状态读取也合并重复请求，避免系统事件堆积。
