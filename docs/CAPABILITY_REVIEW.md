# FuseBar 能力与实现审查

基准：2026-09-16 本地工作树（包含已安装的控制中心第一批），不是只比较已发布 v1.0.1。

## 审查结论

当前不能完整替代系统 Dock、菜单栏与控制中心。圆环是状态整合；设置跳转不是原生控制，系统应用启动入口不是其完整功能的重实现。逐项官方来源与平台边界见 `SYSTEM_CAPABILITY_RESEARCH.md`。

## 已有代码核对

| 位置 | 当前支持 | 缺口 / 处理 |
| --- | --- | --- |
| SystemReader / StatusModel / OrbView | 电量/供电、Wi-Fi/热点、蓝牙连接摘要、音量/静音、稳定提示位 | 不包含设备总控制；保留原始信号未知语义 |
| AudioDevice / StatusStore | 音量写入、输出 UID 选择与回读 | 缺少静音写入；增加能力检测与硬件回读；设备列表只在进入/刷新获取，不能当成事件实时列表 |
| ApplicationShelf | 运行列表、固定、搜索、持久化 | 缺少固定排序、隐藏/显示、Finder 定位；不包含已安装应用全集与系统 Dock 特殊菜单 |
| PopoverView | 状态、应用、声音、设置/帮助 | Wi-Fi/蓝牙仍跳系统设置；增加内部面板；页面高度随权限提示变化，需要统一约束 |
| QuickAction / AppDelegate | Apps/Launchpad、Mission Control、应用打开 | 缺少失败与真实点击跨版本验证；功能属于系统入口 |
| 文件权限 | 无用户文件授权 | 文件/文件夹支持必须通过选择器与安全作用域书签，不硬编码容器外路径 |
| 发行沙箱 | App Store 和 GitHub 共用 Sandbox | 不能因为方法名存在就宣称可控制/退出别的应用。先做沙箱能力验证；未支持时保留明确系统入口 |

## 修正此前规划

- 「正常退出其他应用」不能作为双渠道默认承诺。保留为受沙箱限制的研究项，不添加注定失败的按钮。
- 文件拖放/打开不能笼统归为无公开接口：NSWorkspace 可以打开用户授权文件；多应用拖放交互单独排期。
- 不承诺复刻任意第三方菜单栏插件、动态 Dock 菜单、隐私指示灯或全局媒体会话。
- 应用列表扫描、网络扫描不并入每三秒状态轮询。密码不写入偏好、日志或文档。

## 本轮补全顺序

1. Wi-Fi 内部页：权限说明、显式扫描、当前网络、个人网络连接、开关操作确认、失败反馈。
2. 蓝牙内部页：已配对设备及真实连接状态；没有硬件覆盖前，连接/配对/电源控制留在系统设置。
3. 声音：静音写入与能力检测；不支持的设备禁用，保留系统设置。
4. Dock 应用：隐藏/显示、Finder 定位、固定排序；文件夹入口采用用户授权书签。
5. 整体能力矩阵与后续支持计划；构建、单元测试、只读真机验证与界面检查。系统限制和未经验证的写操作不记为完整支持。
